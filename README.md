# 🎓 PyStudentManager

A simple and beginner-friendly **CLI-based Student Management System** built with Python 🐍✨

PyStudentManager helps you manage student information, marks, percentages, grades, and search through student records — all from the terminal! 💻📚

---

## ✨ Features

* 👨‍🎓 Add new students
* 📋 View all students
* 🔍 Search for a student
* 📝 Store and manage student marks
* 📊 Calculate total marks
* 📈 Calculate percentage
* 🏆 Automatically assign grades
* ✏️ Update student information
* 🗑️ Delete student records
* ✅ Input validation
* 🖥️ Simple menu-driven CLI
